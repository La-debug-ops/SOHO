# Small Office/Home Office Project
## Description

The purpose of this project is to design a network for a company that can be operated independently from the HQ's network. The setup involves using Cisco Packet Tracer to design a network branch for 3 seperate departments, Admin/IT, Finance/HR, and Customer Service/Reception. Each deparment will use different VLANS and required wireless network.
